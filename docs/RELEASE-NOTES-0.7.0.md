Orvio Studio 0.7.0 improves downloads, navigation and local model reuse, and adds desktop utilities.

- Simplified sidebar: six workspace destinations, up to three recent tools, and an independently scrolling middle section. The complete collection stays in All tools; settings remain visible.
- Download drawer: Pause, Resume and Retry failed downloads. Retry information survives restart. Chat and Piper model transfers keep partial bytes; Hugging Face and video transfers resume where their source supports it. Videos retain unfinished source files for retry instead of deleting them. Downloads retain individual progress, speed, percentage and cancellation controls.
- Existing-model discovery: automatically checks common download/model folders and allows a selected folder scan. Reuse GGUF files in place, including recognized Hugging Face/Ollama/LM Studio caches; supported Piper voices and recognized SD cache folders can be attached without downloading weights again. Not every model format or disk location is automatically recognized.
- Expanded image/video library: DreamShaper 8, SDXL Turbo and AnimateDiff Lightning 2-step join the existing models. Model-specific settings and license labels are included. Large models are not recommended for low-memory computers.
- PC Helper: review large files, content-matched duplicates and old temporary files. Nothing is auto-selected. Removal requires review and uses Trash/Recycle Bin, with a check that each file is unchanged since scanning. Mac app review includes the application and matching user-data locations. Windows launches the registered MSI uninstaller or Installed Apps and offers matching app-data folders for review. It does not claim exhaustive registry/driver cleanup.
- Floating tray island: compact status when the main window is hidden, hover expansion and shortcuts for Assistant, Downloads, publishing pause/resume, saving a recording and PC Helper. Can be disabled under Background settings.
- Required updates: enabled by default with a Settings toggle. An available downloaded update requires installation before continuing after active work finishes. Unsigned Mac updates use a manual download flow; the app does not force-close an active recording, stream or transfer to install.

- Desktop pets: choose a cat, puppy or fox; customize its name, corner, local model, speaking voice and wake phrase. Floating chat, push-to-talk, opt-in local wake listening, clear history and an Assistant shortcut. Microphone stays off until explicitly enabled; temporary audio is deleted. Includes original transparent PNG artwork.

Validation: 50 Node tests and 4 Python tests pass, plus production builds. Real Apple Silicon checks include SD Turbo generation (512px, four steps), three simultaneous voice downloads, and a paused Piper download resuming from saved bytes to completion. Pet speech/transcription was also exercised with real local models: a 193,580-byte voice reply was transcribed, no temporary audio remained and the media library was unchanged. Previously validated local chat, voice cloning, transcription, video download, clipping and subtitle rendering remain included. Cleanup tests use fixtures and a fake Trash handler; no personal files were removed. Pet wake listening uses sequential transcription clips, not a dedicated always-on wake engine. The floating pet UI, microphone capture, app, tray window and preview server were not launched for UI testing. Windows/Intel execution, actual uninstallers, complete AnimateDiff generation, live publication and a real installed-version upgrade still require device testing.

Windows x64, Mac Apple Silicon and Mac Intel installers include Python. Builds remain unsigned. Windows updates download automatically; unsigned Mac releases are installed manually. This is a capable download workflow, not full IDM/browser-capture parity: site support, authentication, expiring links and resume support depend on the source, and private/DRM content is not universally downloadable.
