Orvio Studio 0.4.0 gives the desktop app a task-first workspace. The new Overview puts Create a post, the publishing queue, account status, drafts, recent activity, and the AI assistant in one place. Navigation now uses clear Accounts, Assistant, Publishing, Integrations, and Settings destinations instead of promotional sections.

The interface has a higher-contrast desktop shell, a rebuilt first-launch setup, and an appearance preview. You can choose light, dark, or system theme; five accent colors; comfortable or compact spacing; standard or larger text; and reduced motion. Preferences save locally and can be reset from Settings. The existing Meta publishing, chat actions, Google Drive, Cloudinary, AI model discovery, tray operation, and updates remain available.

**Platform notes:** Windows x64 gets a custom NSIS installer and automatic update metadata. Mac Apple Silicon and Intel DMG and ZIP builds are unsigned and unnotarized because no signing credentials are configured; macOS update discovery is manual. Windows may show SmartScreen. Meta, Google Drive, Cloudinary, and AI features need the user's own provider configuration, and scheduled posts require Orvio to be running on an awake, online computer. Live provider sign-in and posting were not exercised for this release.
