Orvio Studio 0.8.0 brings local dictation, a coding workspace and desktop customization.

- Assistant: Chat and Work modes, a focused conversation layout, collapsible history and a new tools library grouped around creating, publishing and managing.
- Work mode: open or create a project, select a downloaded local coding model, inspect/search files and make real edits. Changed files have before/after review and restore controls. The agent can propose terminal commands; each exact command requires an explicit Run action. Commands use your existing development tools and system permissions, not a sandbox. Tasks have bounded context/steps and a stop control.
- Dictation: configurable global shortcut starts recording in the background; press again to transcribe and paste into the previously focused app. Text is also copied. Focus changes prevent automatic paste. Mac requires microphone, Accessibility and potentially Automation permission; some elevated/protected Windows apps may reject simulated paste. Audio is temporary. No cloud transcription is used.
- Writing cleanup: optional downloaded local AI model removes fillers and improves punctuation/formatting. Choose Natural, Professional, Casual, Concise, Email or Bullet points. Context comes from the destination app name and the description you provide; Orvio does not read your screen or documents. If cleanup fails, the original transcript remains available.
- Voice commands: exact English commands support undo, redo, deleting the previous word, selecting all, backspace, bold and italic using the destination app's shortcuts. Spoken punctuation, paragraph, line and bullet markers format dictated text. Formatting support depends on the receiving app.
- Recognition choices: Whisper Tiny/Base/Small (99 languages), Whisper Turbo (100), plus optional Meta MMS for 1,162 languages and variants. MMS downloads a shared ~4 GB model and only the selected language adapter; choose its language manually. MMS weights are noncommercial. Speed/accuracy vary, and larger models are not ideal on low-memory computers. This is not a claim of benchmark parity with Wispr Flow.
- Companion moved into Settings. Live mode is the default for an enabled pet: wake listening starts when it appears, without pressing Talk. It works while using other apps, with a visible mic indicator and stop control. Disable Live mode for push-to-talk. Wake detection uses sequential local transcription clips and can miss words across boundaries; it is not a dedicated realtime wake engine. Dictation temporarily pauses pet listening.
- Dynamic island: top/bottom placement in Settings → Desktop & shortcuts; centered content, fully rounded capsule, small width expansion and inline hover buttons.
- Global shortcuts: customize Assistant, dictation and companion shortcuts; conflicts are reported. All can be disabled.
- Model library retains 12 text/chat, 10 image and 7 video choices plus 16 voice choices. Model-specific image/video dimensions and pipeline settings are used; these choices include checkpoint and motion/base variants. Weights download separately and show license and memory guidance.

Validation: 57 Node tests and 6 Python tests pass, with production builds. Tests cover project confinement, real fixture edits, safe restoration, command approval/cancellation, shortcut conflicts, rewrite context and model install routing. Real local speech/transcription checks from 0.7 remain valid. The app, preview server and floating windows were not launched, per request; global paste, actual microphone capture, shortcut behavior and native window layout need device testing. Not every large image/video model has been generated end-to-end on this computer.

Windows x64 and Mac Apple Silicon/Intel installers include Python. Builds remain unsigned. Windows supports the existing automatic update flow; unsigned Mac updates require manual installation. No browser extension, DRM bypass, universal site downloader or unrestricted autonomous coding shell is implied.

The catalog audit also fixed Zeroscope downloads: its upstream repository provides PyTorch weights, not safetensors. Orvio now selects that format on the current PyTorch engine, and marks this checkpoint unavailable on Intel Mac's older runtime instead of offering a broken download.
