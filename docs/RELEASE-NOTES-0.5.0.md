Orvio Studio 0.5.0 brings local voice and video creation into the redesigned desktop workspace.

- Voice Studio: download seven compact Piper voices for English, Arabic, Hindi, Spanish, French, German and Russian. Chatterbox adds multilingual speech and reference-based voice cloning on Apple Silicon and Windows, preserving its audio watermark. Model downloads include engine dependencies; cloning is a large download and can be slow on CPU.
- Python is included in all three installers. Local engines install into separate environments automatically; no separate Python setup is required. Download progress and cancellation are available, and local tasks run one at a time.
- Video downloader: paste supported public website links, including Instagram and Facebook, without connecting a Meta account. Preview, keep a local library, and save MP4 files to your computer. Optionally select your own exported session-cookie file for account downloads. Login-protected, restricted and unsupported sources may fail; support for every website is not guaranteed.
- Clipping Studio: import or download a video, transcribe it locally with Whisper Tiny, and request highlight suggestions from your configured AI provider. Edit start/end times, export an original or fitted vertical clip, and send it to the publishing composer. Manual clipping works without AI. Find highlights sends the transcript to your selected provider.
- Image Studio: connect local ComfyUI, select an installed checkpoint, generate an image and use it in a post.
- The assistant can schedule complete posts, edit queued posts, list publishing records, generate images and speech, download videos and export clips using its tools. Missing details are requested before publishing.
- Publishing has Scheduled, Posted and All views, with title, caption and time editing for queued posts. Selected navigation items use a clean fill without the leading border.

Validation: production web build and 36 automated tests pass. Bundled Python, Piper voice download and WAV generation, Whisper transcription, a public video download, and FFmpeg vertical clip export were exercised on Apple Silicon. Windows and Intel Mac installers are cross-built; those platforms and the full Chatterbox model have not been exercised on-device. Provider publishing is covered by simulated API tests, not live publication.

Platform notes: Windows x64 includes the NSIS installer and automatic update metadata. Mac Apple Silicon and Intel builds remain unsigned/unnotarized; Mac updates are discovered in-app and installed manually. Windows may show SmartScreen. Cloudinary is currently required for publishing local videos, with a 100 MB upload limit. ComfyUI requires its own local installation/checkpoints. Voice/model licenses are linked in the model library and runtime notices.
