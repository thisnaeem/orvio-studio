# Lip-sync and 3D model notices

Model weights download separately. Check each upstream model card before using generated assets.

- MuseTalk model and reference architecture/audio-conditioning implementation: Tencent Music Entertainment, TMElyralab, MIT. https://github.com/TMElyralab/MuseTalk and https://huggingface.co/TMElyralab/MuseTalk . The MIT notice is included in `licenses/MuseTalk.txt`. Orvio's runner uses its own OpenCV/feathered-crop compositor, not the upstream DWPose/face-parsing workflow.
- Whisper Tiny: OpenAI, MIT. https://huggingface.co/openai/whisper-tiny
- SD VAE FT MSE: Stability AI, CreativeML Open RAIL-M. https://huggingface.co/stabilityai/sd-vae-ft-mse
- Shap-E text and image models: OpenAI, MIT. https://github.com/openai/shap-e and https://huggingface.co/openai/shap-e
- Diffusers: Hugging Face, Apache 2.0. https://github.com/huggingface/diffusers
- Three.js viewer: MIT. https://github.com/mrdoob/three.js

Orvio UI cues in public/sounds are original synthesized PCM audio generated by scripts/create-ui-sounds.py. They contain no third-party recordings or voice assets. Hyperframes is optional development tooling (Apache 2.0), not an inference requirement or app background service.
